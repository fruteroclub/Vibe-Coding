# Introducción - VibeCoding Bootcamp

## 🎯 Bienvenido a VibeCoding

El bootcamp que te enseña a construir apps reales usando IA como herramienta, no como sustituto. En 2 semanas pasas de idea a app desplegada.

---

## 🎯 Misión

Democratizar el desarrollo de software enseñándote a usar IA de forma efectiva. No reemplazamos el conocimiento técnico, lo aceleramos. Aprenderás los fundamentos construyendo proyectos reales desde el día uno.

## 👁️ Visión

Formar una generación de builders que entienden cómo funcionan las apps modernas, saben prompt engineering, y pueden validar ideas en días, no meses. El futuro es de quienes saben combinar pensamiento técnico con herramientas de IA.

---

## 📖 ¿Qué es esta documentación?

Esta es tu guía completa para el bootcamp VibeCoding. Aquí encontrarás todo lo que necesitas para completar las **5 sesiones** del bootcamp (más la configuración inicial en Quick Start): desde los conceptos fundamentales hasta los prompts exactos que usarás con v0 y Claude.

### No es un curso tradicional

Es un sistema de aprendizaje basado en:

- **Construcción activa:** Aprenderás haciendo, no solo viendo videos
- **Progresión estructurada:** Cada sesión construye sobre la anterior
- **Entregables reales:** Cada sesión termina con una app funcional y desplegada

---

## 🗺️ Progresión del Bootcamp

### Sesión 0: Quick Start (15-20 minutos)
**Objetivo:** Configuración inicial del entorno de desarrollo
- Crear cuenta en v0.dev
- Conectar con Vercel
- Preparar entorno de desarrollo
- *Se hace una sola vez*

### Sesión 1: Tu Primer Regenmon (2-3 horas)
**Objetivo:** Construir y desplegar tu primera aplicación web
- **Capa:** Deploy
- **Proyecto:** Regenmon - Mascota virtual que evoluciona
- **Entregable:** App desplegada en internet con URL pública

### Sesión 2: Sistema de Usuarios (2-3 horas)
**Objetivo:** Agregar autenticación y gestión de usuarios
- **Capa:** Auth
- **Proyecto:** Login y registro de usuarios
- **Entregable:** Sistema de autenticación funcional

### Sesión 3: Inteligencia Artificial (2-3 horas)
**Objetivo:** Integrar IA en tu aplicación
- **Capa:** AI
- **Proyecto:** Chatbot con Claude API
- **Entregable:** App con capacidades de IA

### Sesión 4: Base de Datos (2-3 horas)
**Objetivo:** Persistir datos de forma permanente
- **Capa:** Data
- **Proyecto:** Sistema de guardado en la nube
- **Entregable:** Base de datos conectada

### Sesión 5: Frontend Profesional (2-3 horas)
**Objetivo:** Pulir la experiencia de usuario
- **Capa:** UI/UX
- **Proyecto:** Interfaz responsive y accesible
- **Entregable:** App con diseño profesional

## 📊 Las 5 Capas de Toda Aplicación

**Filosofía:** No enseñamos recetas. Enseñamos ingredientes.

Todas las apps usan estas 5 capas. Una vez que las dominas, puedes construir LO QUE SEA.

### 1. 🚀 Deploy
**Descripción:** Hazlo público
**Herramientas:** Vercel, Netlify, GitHub Pages
**Aprenderás:** Cómo publicar tu app para que cualquier persona en el mundo pueda acceder

### 2. 🔐 Auth
**Descripción:** Login y usuarios
**Herramientas:** Privy, NextAuth, Supabase Auth
**Aprenderás:** Sistemas de autenticación seguros donde cada usuario tiene su cuenta y datos privados

### 3. 🤖 AI
**Descripción:** Inteligencia artificial
**Herramientas:** Claude API, OpenAI, Replicate
**Aprenderás:** Integrar modelos de lenguaje y visión para que tu app piense y responda

### 4. 💾 Data
**Descripción:** Base de datos
**Herramientas:** Supabase, Firebase, PostgreSQL
**Aprenderás:** Guardar y recuperar datos, desde localStorage hasta bases de datos en la nube

### 5. 🎨 UI/UX
**Descripción:** Interfaz de usuario
**Herramientas:** Tailwind CSS, Radix UI, Framer Motion
**Aprenderás:** Crear interfaces responsive, accesibles y profesionales

## 🎓 Metodología de Aprendizaje

### Principio Central: Learning by Doing

1. **Construye primero, entiende después**
   - Copia el prompt
   - Ve el código generado funcionar
   - LUEGO lee el material de apoyo

2. **Progresión incremental**
   - Cada sesión agrega UNA capa nueva
   - No intentamos enseñar todo a la vez
   - Builds sobre conocimiento previo

3. **Entregables reales**
   - No ejercicios teóricos
   - Cada sesión termina con una app desplegada
   - Portfolio real al finalizar

4. **Prompt engineering como skill**
   - Aprendes a comunicarte con IA
   - Skill transferible a cualquier herramienta
   - Más valioso que sintaxis específica
